# Деплой и привязка к боту MAX

## Почему я не могу «дать ссылку» или арендовать VPS за вас
Ссылка на Mini App — это адрес, где **запущено** приложение. Пока оно нигде не
опубликовано, ссылки не существует. Арендовать сервер/зарегистрировать хостинг
за вас я тоже не могу: это требует создать аккаунт, принять оферту и ввести
телефон/карту — такие действия выполняете только вы. Всё остальное уже готово:
код, единый Docker-образ, Render-блюпринт и прод-compose с авто-HTTPS.

Данные вашего бота (уже подставлены в конфиги):
- Bot API: `https://botapi.max.ru` (проверено вашим токеном)
- `MAX_BOT_USERNAME = id710305301921_1_bot` — бот «Задачи для бухгалтера»

## Вариант 1 — Render (быстрее всего, без своего сервера, бесплатно)

Нужны бесплатные аккаунты **GitHub** и **Render** (в Render вход через GitHub).

**Шаг 1. Отправьте код на GitHub.**
Создайте на github.com пустой репозиторий (без README), затем в терминале:
```
cd "/Users/evgenij/задачи для бухгалтера"
git remote add origin https://github.com/ВАШ_ЛОГИН/max-tasks.git
git branch -M main
git push -u origin main
```

**Шаг 2. Создайте сервисы из блюпринта.**
Render.com → **New → Blueprint** → выберите ваш репозиторий → **Apply**.
Render сам создаст PostgreSQL и веб-сервис по файлу `render.yaml`.

**Шаг 3. Задайте секреты.**
В веб-сервисе → **Environment** впишите:
- `MAX_BOT_TOKEN` — ваш токен бота;
- `ADMIN_MAX_USER_ID` — ваш MAX ID (если не знаете — пока поставьте `1`, см. Шаг 5).

**Шаг 4. Дождитесь деплоя.**
Вверху страницы сервиса появится URL вида `https://max-tasks-xxxx.onrender.com`.
**Это и есть ссылка на Mini App.**

**Шаг 5. Узнайте свой MAX ID и станьте админом.**
Напишите боту «Задачи для бухгалтера» команду `/start` — он ответит и пришлёт
«Ваш MAX ID: …». Вставьте это число в `ADMIN_MAX_USER_ID` (Environment) и
сохраните — сервис перезапустится, вы станете администратором.

**Шаг 6 (необязательно).** Впишите `MINI_APP_URL` = тот же URL (для кнопки
«Открыть приложение» в уведомлениях).

**Шаг 7. Привяжите ссылку к боту** (см. раздел «Привязка» ниже).

> Нюансы бесплатного Render: сервис «засыпает» при простое (первый вход после
> паузы — 30–60 с; пока спит, бот не шлёт уведомления), бесплатная БД живёт ~30
> дней. Для постоянной работы — платный план (~$7/мес) или Вариант 2 (VPS).

## Вариант 2 — свой VPS + бесплатный домен DuckDNS (работает постоянно)

Нужен VPS (Timeweb Cloud / Aeza / VDSina / Selectel, Ubuntu 24.04, ~2 ГБ RAM),
оплата — ваша.

**Шаг 1.** Создайте VPS, запишите его IP.

**Шаг 2. Бесплатный домен.** На duckdns.org войдите, создайте поддомен (напр.
`buhtasks`) и укажите IP вашего VPS → получите `buhtasks.duckdns.org`.
Let's Encrypt выдаст для него настоящий HTTPS.

**Шаг 3. Установите Docker на сервере:**
```
curl -fsSL https://get.docker.com | sh
```

**Шаг 4. Залейте проект на сервер** (с вашего Mac):
```
cd "/Users/evgenij/задачи для бухгалтера"
rsync -av --exclude node_modules --exclude dist --exclude .git ./ root@IP_СЕРВЕРА:/opt/max-tasks/
```
(или `git clone`, если выполнили Шаг 1 из Варианта 1)

**Шаг 5. Создайте `.env` на сервере:**
```
cd /opt/max-tasks
cp env.example .env
nano .env
```
Заполните: `POSTGRES_PASSWORD`, `DATABASE_URL` (тот же пароль), `MAX_BOT_TOKEN`,
`ADMIN_MAX_USER_ID`, `MAX_BOT_USERNAME=id710305301921_1_bot`,
`DOMAIN=buhtasks.duckdns.org`, `ACME_EMAIL=ваша@почта`,
`MINI_APP_URL=https://buhtasks.duckdns.org`.

**Шаг 6. Откройте порты и запустите:**
```
ufw allow 22,80,443/tcp || true
DOMAIN=buhtasks.duckdns.org docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
```

**Шаг 7.** Через ~1 минуту `https://buhtasks.duckdns.org` — ваша ссылка.
Привяжите её к боту (раздел ниже). MAX ID узнаёте так же — через `/start`.

## Привязка ссылки к боту (общее для обоих вариантов)

В MAX откройте **@MasterBot** → выберите бота «Задачи для бухгалтера» →
раздел **Mini App / веб-приложение** → вставьте ваш `https://…`-URL → сохраните.

## Проверка после привязки
1. Напишите боту `/start` → придёт приветствие и ваш MAX ID.
2. Откройте Mini App: админ видит **Главную / Задачи / Люди / Отчёты**.
3. Попросите сотрудника написать боту `/start` или открыть Mini App — он появится
   в разделе **Люди**.
4. Создайте ему задачу (**+ Новая задача**) → ему придёт уведомление «📋 Новая задача».
5. Сотрудник жмёт «Отметить выполненной» → вам придёт «✅ Задача выполнена».
6. Еженедельный отчёт — по понедельникам в 09:00 (часовой пояс `APP_TIMEZONE`).
